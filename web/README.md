# Fretspace Web

Web companion for Fretspace, the visionOS guitar-practice app. Currently a dark-themed dashboard shell (Practice Stats, Track Library, Account placeholders); no routing or state management yet.

## Stack

- React 19 + Vite + TypeScript
- Tailwind CSS v4 (via `@tailwindcss/vite` plugin)

## Dev commands

```sh
npm install
npm run dev      # dev server (http://localhost:5173)
npm run build    # typecheck + production build to dist/
npm run preview  # preview the production build
```
